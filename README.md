# MML Intranet : CTF web côté client

Intranet fictif de la **Mutuelle des Monts du Lyonnais**, volontairement vulnérable, pour s'entraîner aux failles web côté client.

5 services internes à déverrouiller, 5 drapeaux à récupérer au format `MML{...}`. Les niveaux sont classés du plus facile au plus difficile.

## ▶️ Jouer

En local : télécharge le dépôt et ouvre `index.html` dans ton navigateur. Aucun serveur ni installation nécessaire.

## Règles

- Tout se passe dans le navigateur : ton seul outil, ce sont les **DevTools** (code source, console, stockage, inspecteur).
- Les drapeaux sont calculés à partir de la bonne réponse : chercher `MML{` dans le code ne sert à rien.
- Le bouton **Réinitialiser la progression** en bas de page remet tout à zéro.
